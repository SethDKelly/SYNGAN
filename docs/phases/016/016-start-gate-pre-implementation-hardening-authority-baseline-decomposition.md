## Problem statement

SYNGAN's semantic/architecture foundation is stronger than its current long-term knowledge and agent operating topology.

Material pre-implementation concerns include:

- current authority and historical phase work remain physically intermingled;
- 152 phase Markdown records remain inside the active docs knowledge surface;
- phase/audit/consolidation material repeats durable conclusions already promoted elsewhere;
- AGENTS.md currently lists 25 startup documents, encouraging broad context loading;
- project-specific OKF intent exists, but a strict producer profile/generated projection/conformance path is not yet established;
- no deterministic stable-reference/current-owner resolver exists;
- tool-neutral agent workflows, context budgets, action/change classes and adapter rules are not yet a complete repository-owned system;
- no separate agentic/documentation conformance lane protects routing/context/authority drift;
- implementation packages and non-semantic engineering preflight policies are not yet standardized for the next sustained delivery program.
