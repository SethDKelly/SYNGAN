## Rediscovery burden

008-G does not restore a candidate merely because the idea is important or because architecture gives it a resource, identity, status or durable representation.

Promotion requires all of:

1. distinct current product-facing purpose;
2. independent state/history;
3. independently owned behavior;
4. an operational principle demonstrating the candidate's purpose;
5. clean authority boundary;
6. appropriate domain genericity;
7. current O1-O16 need;
8. coordination benefit sufficient to justify another state owner.

This intentionally makes 008-G a falsification pass rather than a symmetry exercise.

## Principal finding 1 — no original rejected/deferred candidate now requires restoration

All original exclusions remain correctly classified under current evidence.

Important retained distinctions do not require standalone concepts:

```text
Generation Request  -> Generation pre-commit state
Condition           -> Generation-owned request semantics
Attempt             -> Execution history
Artifact Identity   -> representation/integration
Reproducibility     -> cross-cutting contract assembled from accepted state
Privacy             -> heterogeneous; future mechanism-specific discovery only
Dataset Identity    -> representation/integration
Relationship        -> descriptive structural state in Data Meaning
Use/Release Decision-> external authority
Source Profile      -> supporting method/observation
```

No current O1-O16 pressure supplies an independent purpose/action lifecycle missing from those dispositions.

## Principal finding 2 — Relationship remains subordinate after O15 became current scope

This was the most important historical candidate to replay because Phase 008-B elevated single-table, time-series and multi-table shared-key/composite topology to current problem scope.

008-G confirms the Phase 006-G disposition still holds.

Structural relationship meaning is first-class, but its purpose/authority/lifecycle remain Data Meaning-shaped: descriptive interpretation is declared/reviewed/revised/bound historically. Prescriptive referential/cardinality/temporal validity belongs to Constraint; request-specific topology/horizon/quantity belongs to Generation; support belongs to Strategy; findings belong to Evaluation/Evidence.

No independent Relationship behavior remains once those owners are respected.

**Disposition: no standalone Relationship concept.**

## Principal finding 3 — future formal DP remains a real rediscovery trigger, not a current concept

008-G confirms the generic Privacy candidate remains invalid because it conflates empirical disclosure risk, formal mechanisms, confidentiality/access policy and organizational release authority.

A future composable differential-privacy capability could establish an independent mechanism-specific concept if it introduces reusable privacy-unit/adjacency, budget allocation/reservation, consumption, composition and exhaustion state across activities.

That capability is outside the current baseline. Therefore no DP concept is accepted and no DP implementation is authorized.

## Principal finding 4 — resource/recovery/security mechanisms remain non-concepts

The later Phase 006 probes remain correctly classified:

- authority epochs/fences are recovery realization;
- recovery is Execution/deployment behavior;
- resource readiness/admission/backpressure are operational/deployment policy;
- approximation is owner-specific semantics;
- degraded operation is capability-specific, not one coherent lifecycle;
- cost/quota remains external/deployment policy;
- redaction is security/view semantics;
- authorization/credentials/capability grants are security authority/representation, not synthetic-data domain concepts.

Their importance to correctness does not establish independent product purpose.

## Principal finding 5 — Synthetic Output is the strongest new missing-candidate challenge but does not currently pass

A completed synthetic output outlives Generation, can be evaluated, referenced in Provenance and consumed externally. That makes it superficially similar to Learned State or Evidence.

008-G nevertheless rejects a separate Output concept at current scope because SYNGAN currently gives the output no independent state-changing lifecycle beyond Generation's result semantics.

Generation already owns candidate-versus-completed state and the one authoritative completed logical output association. Availability, storage location, retention, export authorization and physical lifecycle are downstream integration/security concerns. Evaluation observes output without mutating it; external use does not create SYNGAN-owned output behavior.

Creating Output now would therefore split Generation result state without independent behavior.

A future product scope with output publication/versioning/retirement/transformation/release management would be a valid rediscovery trigger.

## Principal finding 6 — Source, Dependency and Platform/Security subjects remain references/context

Source datasets, external artifacts/dependencies, platform capabilities and credentials materially affect commitment, reproducibility, no-egress behavior and execution readiness.

But current ownership remains coherent:

- Data Meaning describes source semantics;
- activities bind stable source state;
- Strategy declares dependencies/capabilities/limitations;
- Execution/runtime resolves operational availability;
- Provenance records material use;
- security/platform layers own current authorization and credentials.

No generic Source, Dependency, Authorization, Secret or Platform Capability concept is justified.

## Principal finding 7 — topology/text vocabulary does not become concepts

Current O15/O16 scope does not require standalone `TimeSeries`, `Series`, `Sequence`, `Table`, `Text`, `Tokenizer`, `Language Model`, `GenerationMode` or `DataTopologyMode` concepts.

Topology and text behavior remain distributed across existing purpose owners. Algorithm/runtime representations remain Strategy/dependency concerns.

This result does not prohibit typed future API/specification representations of those words.
