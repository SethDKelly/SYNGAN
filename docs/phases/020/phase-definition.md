# Phase 020 — Complete Minimal End-to-End Vertical Workflow

## 017-F baseline

This is a durable high-level planning definition established by Phase 017-F.

It constrains a future start gate but does not authorize execution. Actual subphases and IPKG
manifests must be derived from then-current repository evidence after explicit human selection.

## Role

Deliver one complete useful workflow through the smallest supported reference path.

## Entry intent

MVP-M1 accepted; explicit human selection; Phase 020 start gate derives vertical-increment packages.

## Required exit intent

MVP-M2: one package-level workflow composes preparation/control, execution, generation, evidence, provenance/history, result access, and bounded recovery/reconstruction.

Expected capability milestone: MVP-M2.

## Prospective package families

- minimal successful reference workflow
- result/evidence/history reconstruction
- failure/retry/recovery path
- public workflow integration evidence

These are planning families, not package IDs or authorization sources.

## Non-goals

Topology catalog completion, Spark realization, public release, or provider/scale qualification.

## Authorization rule

Execution is NOT AUTHORIZED by this definition. Passing this phase never authorizes the next phase.
