# 011-A — Validation Authority, Evidence Hierarchy, Probe Taxonomy & Misfit/Reopen Rules

## Objective

Establish the canonical audit method for Phase 011 before any substantive specificity, familiarity, integrity, synergy or misfit verdict is made.

011-A is design-only. It does not score G1-G7, alter concepts/synchronizations/mappings, select architecture, or authorize implementation.

## Evidence hierarchy result

011-A establishes eight evidence layers from current problem/concept authority through external ecosystem analogues.

Lower layers may expose a counterexample or feasibility problem but cannot silently become upstream semantic authority.

Evidence roles are distinguished as:

```text
ER-N  normative current authority
ER-O  observed current-design consequence
ER-C  counterexample / falsification evidence
ER-A  analogue / familiarity comparison
ER-F  feasibility / physical-constraint evidence
ER-H  hypothesis
```

## Finding-record result

Every material Phase 011 finding is now expected to record subject, proposition, probe, expected invariant, evidence role, concrete semantic consequence, materiality, misfit class, smallest affected authority, disposition and revalidation blast radius.

A concern without a concrete semantic consequence is insufficient by itself to reopen design.

## Materiality result

011-A separates severity from location:

```text
MAT-0  observation
MAT-1  bounded clarity / quality concern
MAT-2  material design defect or credible material risk
MAT-3  conceptual blocker
```

MAT-3 prevents positive Phase 011 exit while unresolved.

## Quality criteria established

011-A defines reusable criteria for:

- specificity (`SP-1` through `SP-7`);
- familiarity comparison (`FA-1` through `FA-8`);
- integrity (`IN-1` through `IN-12`);
- synergy/simplicity/generic fitness (`SY-1` through `SY-10`);
- scenario-quality misfit (`SC-1` through `SC-10`).

No substantive verdict is made yet.

## Misfit/reopen result

The Phase 011 misfit classes remain:

```text
M0  no defect / accepted observation
M1  local Phase 011 clarification
M2  Phase 010 mapping / experience defect
M3  Phase 009 dependence / synchronization / composition defect
M4  individual-concept defect
M5  problem / actor / outcome / scope defect
M6  representation / architecture-only
M7  implementation-only
M8  future-scope rediscovery trigger
```

011-A adds the smallest-authority reopen rule:

1. state the violated semantic claim;
2. locate the smallest canonical owner;
3. classify the misfit;
4. reopen only that authority first;
5. correct canonical authority before summaries;
6. identify materially dependent conclusions;
7. revalidate only affected downstream conclusions;
8. record supersession/compatibility effects.
