# 010-D — Linguistic Mapping, Vocabulary, Typed Status & Disclosure Semantics

## Objective

Close Phase 010's F3 linguistic-mapping obligation by defining actor/programmatic vocabulary that preserves concept ownership, semantic dimensions, historical scope, uncertainty and disclosure distinctions established upstream.

010-D entered after 010-C with F1/F2 currently closed and F3 partial-to-strong.

## Canonical authority established

010-D creates:

- [Linguistic Mapping, Vocabulary, Typed Status & Disclosure Semantics](../../../mapping/linguistic-mapping-vocabulary-typed-status-disclosure-semantics.md)

This becomes the current Phase 010 linguistic authority for later physical-surface mapping.

## Principal result

SYNGAN does **not** have one generic status state machine.

010-D separates at least:

```text
revision/current-use status
semantic activity lifecycle
contextual assessment
Execution/Attempt operational lifecycle
Generation material finality
Evidence finding / claim strength
Constraint handling / applicability
Disclosure state
historical-knowledge quality
```

These dimensions may be composed in a view but may not be collapsed into one owner.

## Owner-qualified language

010-D establishes owner-qualified wording where ambiguity matters, including:

```text
Generation completed
Execution completed operationally
Evaluation completed
Learning prerequisite assessment: ready with limitations
Generation compatibility: indeterminate
Constraint handling: validated later
Evidence finding: violated
```

Unqualified `run complete`, `validation passed`, `model valid`, `output safe`, `quality passed` and similar phrases are rejected where they obscure the exact semantic claim.

## Lifecycle/current-use result

Reusable authority/result language now distinguishes superseded, retired, restricted, stale/obsolete, inapplicable and invalidated rather than flattening them into generic deprecated/invalid state.

Semantic activities preserve proposal, validation/assessment, commitment, active realization, cancellation request where material, semantic completion/failure/cancellation.

Execution remains operationally distinct.

## Generation finality result

Language preserves:

```text
partial materialization
candidate materialization
candidate complete / awaiting required validation
completed output
abandoned/quarantined non-final material
```

Physical materialization alone cannot be described as semantic Generation completion.

## Evaluation/Evidence result

A successful Evaluation may produce unfavorable Evidence.

`Evaluation completed` therefore does not mean the subject passed, output is safe, privacy is established or release is approved.

Evidence claim-strength qualifiers remain explicit where material: exhaustive/universal for stated scope, deterministic bounded/certificate-backed, statistical, approximate/sketch-based, and diagnostic/partial.

No universal Evidence pass/fail enum is introduced.

## Disclosure result

010-D finalizes mapping meanings for:

```text
visible
authorized summary / redacted
withheld
unavailable
unknown
absent
```

`not applicable` is separate from absence.

Where revealing existence is itself sensitive, the outward actor boundary may intentionally collapse distinctions without mutating canonical state.

## Historical-knowledge result

010-C placeholders are linguistically normalized to:

```text
directly retained
reconstructed
partial / incomplete
history unavailable
history indeterminate
```

History quality remains orthogonal to disclosure.

## Ecosystem vocabulary result

High-risk words such as model, run, job, artifact, metric, metadata, validation, valid, passed, quality, safe, private, reproducible, current, latest and complete now require semantic qualification where ambiguity matters.

Compatibility vocabulary such as fit, train, sample and synthesizer remains permitted only when mapped explicitly back to canonical SYNGAN semantics.
